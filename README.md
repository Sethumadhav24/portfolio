# S Sethu Madhav - Portfolio Website

This is a portfolio website showcasing my projects, skills, and experience as an AI/ML Engineer. It is built using React, Tailwind CSS, and Framer Motion.

## About Me

I am a passionate AI/ML Engineer with 2 years of experience building practical AI solutions across Generative AI, LLMs, RAG, Computer Vision, and Edge AI. I specialize in developing, fine-tuning, and deploying AI models on both cloud and edge platforms.

## Technologies Used

- **React:** Frontend library for building user interfaces.
- **Tailwind CSS:** Utility-first CSS framework for custom styling.
- **Framer Motion:** Animation library for creating smooth, micro-animations and transitions.
- **React Icons:** Custom icons pack.

## Getting Started

To run this project locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/Sethumadhav24/portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:5173](http://localhost:5173) to view the website in your browser.

## Deployment

This website is automatically built and deployed via **Vercel** on pushes to the `master` branch.
